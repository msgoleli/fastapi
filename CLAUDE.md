## Codebase Overview

_Patient_ is a demo application for _FastAPI_, _Pydantic_, _Strawberry GraphQL_,
_SQLAlchemy_ for persistent data in _PostgreSQL_, _smtp_ for mailing, and _Keycloak_ for
for _OpenID Connect_ (OIDC) and _OAuth 2_. This is a monorepo using _uv_ as package and
project manager.
